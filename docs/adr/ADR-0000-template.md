## Context

State the problem, constraints, affected interfaces, and why a decision is needed now.

## Decision

State one precise decision. Include versions or compatibility promises when relevant.

## Alternatives considered

For each credible alternative, record benefits, costs, risks, and reason not selected.

## Consequences

Describe security, reliability, performance, data, deployment, migration, licensing, testing, and support effects.

List tests or evidence that prove the decision works.

## Rollback or migration

State how to reverse or supersede the decision without losing customer data or production continuity.
